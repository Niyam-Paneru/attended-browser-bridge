# Safety boundary

The public policy core requires a trusted caller for grants, page observations and verified business outcomes. The demonstration adapter is deliberately limited to a synthetic loopback ticket site and one exact permitted POST. It never uses a real customer account, browser profile, persisted login state or external target.

The durable journal is for trusted local storage. A malformed record fails closed. Do not delete unresolved reservations to retry. This is a review fixture, not a production permission service or browser product.
